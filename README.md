## Repository Structure

Each major topic is organized into separate sections for better navigation.

For example:

```text
4_Spring Core/
├── Notes/
└── Codes/
```

The **Notes** folder contains theoretical concepts, explanations, and interview-oriented material.

The **Codes** folder contains practical implementations and examples related to the topic.
